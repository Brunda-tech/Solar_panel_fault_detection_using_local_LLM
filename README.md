# Solar_panel_fault_detection_using_local_LLM
An IoT and AI-powered solar panel fault detection system using ESP32, LSTM, GRU, and a Local Gemma LLM with RAG.
The system is designed for real-time monitoring, intelligent diagnostics, and predictive maintenance of solar panels.
It combines IoT-based monitoring with AI-driven fault detection to identify and analyze potential issues.
The integration of LSTM and GRU models supports intelligent fault prediction, while the Local Gemma LLM with RAG provides diagnostic assistance.
This project aims to provide a smart and efficient approach to solar panel monitoring, fault detection, and predictive maintenance.
